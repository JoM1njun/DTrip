1. main.html -> index.html로 변경 예정
2. app.js : 화면 전환을 위한 파일
3. js/components : 기능들을 위한 폴더 ex) DB에서 데이터 가져와 표시, 검색, 카테고리 등
4. js/screens : 말 그대로 화면들
5. js/database : DB 연결을 위한 폴더 (건드릴 일 없음)
6. css : 각 화면과 기능별로 css 나눠놨음
7. assets : 각 이미지들
8. gitignore : commit과 push 시키지 않을 파일들 지정
9. package들 : 내가 사용중인 버전 (Node.js)
